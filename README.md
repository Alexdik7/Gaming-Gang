# Gaming Gang

Sammlung von Browser-Spielen, spielbar am Handy als installierbare Web-App (PWA).

**Live:** https://alexdik7.github.io/Gaming-Gang/

## Spiele

| Spiel | Ordner | Beschreibung |
|---|---|---|
| The Plug from 52 | [`plug52/`](plug52/) | Fiktives Street-Tycoon-Spiel: Farm, Produktion, Aufträge, Kontakte, 10 Regionen, 60 Level. |
| Legends United | [`legends/`](legends/) | Kreaturen-RPG im Handheld-Stil mit 150 Kreaturen, Brutstätte & Mutationen, 8 Arenen, Top 4 & Champion, Raids zu viert, Surfen, Eis-, Dunkel-, Schalter- und Schieberätseln, Team Eklipse und Online-Koop (Kämpfen, Tauschen, Koop-Bosse) für bis zu 4 Spieler. Details in [`legends/README.md`](legends/README.md). |

## Neues Spiel hinzufügen

1. Neuen Ordner anlegen, z. B. `mein-spiel/`, mit `index.html`, `manifest.webmanifest`, `sw.js` und Icons.
2. Auf der Startseite `index.html` eine neue Karte im Bereich `.games` eintragen.
3. Pushen. GitHub Pages veröffentlicht automatisch.

## Auf dem Handy installieren

- **iPhone:** Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- **Android:** Link in Chrome öffnen → ⋮ → „App installieren“.
